# GovPrep-Pro

## 🚀 Overview
GovPrep-Pro is a performance-focused exam preparation platform designed to help students prepare smarter, track progress effectively, and improve exam outcomes through structured practice.

## 🎯 Problem It Solves
Most exam-prep platforms act as digital content libraries. GovPrep-Pro focuses on performance, analytics, and targeted improvement instead of passive studying.

## 🛠 Tech Stack
- Frontend: React, TypeScript, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB
- Authentication: JWT
- Deployment: Vercel (Frontend), Render (Backend)

## ✨ Key Features
- Secure user authentication
- Topic-wise and exam-wise practice
- Performance analytics dashboard
- Progress tracking over time
- Responsive UI for mobile and desktop

## ⚙️ Local Setup
1. Clone the repository  
   `git clone https://github.com/ralok6385/GovPrep-Pro.git`

2. Install dependencies  
   `npm install`

3. Start the development server  
   `npm run dev`
